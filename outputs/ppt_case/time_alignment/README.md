# 自适应时间对齐图示说明

## 图文件

- `time_alignment_ppt.png`：300 DPI，16:9 科研汇报图。
- `time_alignment_ppt.svg`：PPT 可编辑矢量图。

## 一句话图注

在 `EVT2_006` 时间范围内，以 101 组 DAIR 官方车路 LiDAR 帧对为评价依据；在明确标注的合成时钟抖动与网络延迟下，事件时间自适应窗口比到达时间固定窗口更稳定地恢复官方对应关系。

## 面板含义

- A：注入合成网络延迟后，两路到达时间相对理想事件时间发生不同程度偏移。
- B：经过初始跨源时间偏移校准后，两路事件时间重新接近一致性对角线。
- C：Improved 窗口依据采样间隔和观测到的延迟波动动态变化；橙色区域是合成延迟突发区间。

## 数据口径

- 真实数据：官方帧配对、车端/路侧 LiDAR 事件时间、Case 时间范围。
- 仿真数据：时钟抖动、到达延迟、延迟突发。
- 算法估计：校准后的事件时间、自适应匹配窗口、输出配对。
- 结果不代表 DAIR 的实际网络延迟，也不代表真实部署性能。

## 配套数据

- `time_alignment_config.json`：随机种子、扰动参数和算法配置。
- `time_alignment_samples.csv`：逐样本真实时间、合成扰动和窗口大小。
- `time_alignment_matches.csv`：两种方法输出的配对结果。
- `time_alignment_metrics.csv`：覆盖率、正确配对率、匹配精度和时间误差。
