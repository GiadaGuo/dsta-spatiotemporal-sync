# 模态可信度动态加权可行性判断

- 现有 `spatial_matches.csv` 含815条同帧一对一候选匹配；车辆端键和路侧键均无重复，中位空间残差0.929m，P90为1.551m。
- 匹配由官方车路帧关系、同类别约束、5m空间阈值和逐帧匈牙利分配产生。它能支持相对一致性分析，但不能保证跨帧目标身份连续。
- 数据没有独立的测绘级参考位置。直接以任一来源或两源均值作为绝对真值，会把融合输入重复用于评价并造成数据泄漏。
- 因此不采用方案A做“真实定位精度提升”量化，而采用方案B：96点真实轨迹只作为隐藏评价参考，生成两个相互独立的受控噪声通道。
- 真实参考不参与动态权重计算；前20点为校准边界，后76点为测试；报告10个固定随机种子的均值和标准差。
- 结论只能表述为受控噪声场景下的动态加权效果，不能称为真实车路双源融合精度。
