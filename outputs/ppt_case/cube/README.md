# DSTA 统一时空数据立方体交付说明

## 启动交互页面

```bash
.venv/bin/streamlit run apps/dsta_cube.py
```

原有事件分析页面 `app.py` 未被覆盖。

## 交付内容

- `unified_observations.parquet`：8,327 条观测级统一记录。
- `unified_cube_states.parquet`：830 条网格窗口级状态，覆盖 13 个时间切片。
- `unified_data_schema.md`：字段粒度、来源和真实/计算/仿真边界。
- `dsta_cube_ppt.png`：300 DPI 静态立方体图。
- `dsta_cube_ppt.svg`：可编辑矢量图。

## 可视化规则

- X/Y：DAIR 真实世界坐标，单位米。
- T：相对窗口 0 的事件时间，单位秒，不是地理高度。
- 一个点：一个 `window_id × grid_id` 状态，不是单辆车。
- 点大小：该网格窗口的观测记录数。
- 颜色：交互页面可切换观测量、平均速度、来源覆盖和质量状态。
- 紫色轨迹：`EVT2_006` 下游事件成员，仅作为应用验证。
- 静态图：显示事件周围 80m 范围内的 192 个状态；完整 830 个状态全部保留在数据文件和交互页面中。
