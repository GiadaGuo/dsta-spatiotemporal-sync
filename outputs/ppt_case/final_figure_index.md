## 图 2｜自适应时间对齐

- **算法步骤**：1 自适应时间对齐。
- **PNG / SVG**：`outputs/ppt_case/time_alignment/time_alignment_ppt.png` / `time_alignment_ppt.svg`
- **数据来源**：EVT2_006 时间范围内 101 组真实官方 LiDAR 帧对。
- **实验口径**：在真实时间戳副本上注入网络延迟与采样抖动；比较固定到达时间窗口和自适应事件时间窗口。
- **关键数值**：正确配对率 67.33%→98.02%；覆盖率 91.09%→98.02%；P90 时间误差 103.60→5.70 ms。
- **推荐图注**：在受控延迟与抖动下，自适应事件时间窗口提高了正确配对覆盖并降低尾部时间误差。
- **真实性与局限性**：帧对和时间戳真实，延迟与抖动为仿真；不能表述为现场网络实测提升。

## 图 3｜统一空间映射与质量感知网格

- **算法步骤**：2 统一空间映射与多尺度网格。
- **PNG / SVG**：`outputs/ppt_case/spatial_mapping/spatial_mapping_ppt.png` / `spatial_mapping_ppt.svg`
- **数据来源**：真实冻结测试集 1,235 条观测、既有三种网格定义。
- **实验口径**：相同 ROI、100% 覆盖率、统一不超过 200 个叶网格预算；不重新优化。
- **关键数值**：固定/密度/质量感知平均量化误差 12.40/11.33/8.60 m；网格数 144/126/186。
- **推荐图注**：在统一预算下，质量感知网格取得最低平均量化误差；EVT2_006 标记用于贯穿案例定位。
- **真实性与局限性**：全部空间观测真实；质量感知方案的 P90 不是三者最低，不能宣称全面占优。

## 图 4｜乱序与缺失补偿

- **算法步骤**：3 乱序与缺失补偿。
- **PNG / SVG**：`outputs/ppt_case/dsta_validation/missing_compensation/missing_compensation_ppt.png` / `missing_compensation_ppt.svg`
- **数据来源**：同一 DAIR 序列中一段 96 点真实车端连续轨迹。
- **实验口径**：前 20 点校准、后 76 点测试；注入 10%–40% 缺失与 22% 到达乱序；比较到达时间插值和事件时间重排加连续性插值。
- **关键数值**：40% 缺失时 Baseline/DSTA RMSE 1.332/0.179 m；DSTA 恢复覆盖率 100%，重排后逆序数为 0。
- **推荐图注**：在真实轨迹的受控缺失和乱序副本上，事件时间重排与连续性插值稳定恢复被隐藏观测。
- **真实性与局限性**：参考轨迹真实但不是外部测量真值，也不是 EVT2_006 成员；缺失与乱序为 synthetic injection。

## 图 5｜模态可信度动态加权

- **算法步骤**：4 模态可信度动态加权。
- **PNG / SVG**：`outputs/ppt_case/dsta_validation/reliability_weighting/reliability_weighting_ppt.png` / `reliability_weighting_ppt.svg`
- **数据来源**：96 点真实参考轨迹上生成的两条独立受控噪声通道。
- **实验口径**：参考轨迹不参与权重计算；10 个固定随机种子；通道 B 在 4–6 s 阶段性退化并有 20% 不可用。
- **关键数值**：退化阶段等权/动态加权 RMSE 2.150±0.300/0.508±0.084 m；B 平均权重由 0.373 降至 0.050。
- **推荐图注**：当仿真通道 B 阶段性退化时，因果动态权重降低其贡献，并在当前受控噪声配置下降低融合误差。
- **真实性与局限性**：双通道是仿真，不是真实车路双源融合；参考坐标不是独立测绘真值。

## 图 6｜时空一致性联合校验

- **算法步骤**：5 时空一致性联合校验。
- **PNG / SVG**：`outputs/ppt_case/dsta_validation/consistency_validation/consistency_validation_ppt.png` / `consistency_validation_ppt.svg`
- **数据来源**：815 条候选跨源匹配、126 组官方帧对、真实时间/空间/同轨迹连续性残差。
- **实验口径**：358 条正常校准、457 条独立测试；测试副本注入时间、空间、轨迹和组合异常；测试标签不参与调参。
- **关键数值**：中强度 OR：F1=0.832、FPR=0.130、Recall=0.776；联合：F1=0.686、FPR=0.022、Recall=0.529。
- **推荐图注**：多维联合校验将误报率从 0.130 降至 0.022，但召回率由 0.776 降至 0.529，体现更保守而非全面更优的策略。
- **真实性与局限性**：候选匹配不是身份真值；异常标签为 synthetic，正常候选中仍可能包含误匹配。

## 图 7｜统一时空数据立方体

- **算法步骤**：统一时空数据流输出。
- **PNG / SVG**：`outputs/ppt_case/cube/dsta_cube_ppt.png` / `dsta_cube_ppt.svg`
- **数据来源**：`unified_observations.parquet` 与 `unified_cube_states.parquet`，由现有真实数据严格生成。
- **实验口径**：X/Y 为真实世界坐标，T 为相对事件时间；观测级和网格窗口级分表，不把实验扰动写入真实表。
- **关键数值**：8,327 条观测、830 条网格窗口状态、13 个时间切片、186 个自适应网格。
- **推荐图注**：DSTA 将真实车路观测组织为带时间、空间、来源、质量和 provenance 的双粒度三维时空数据结构。
- **真实性与局限性**：立方体主体为真实观测与严格聚合；T 不是地理高度，质量字段不等于外部真值质量评分。
